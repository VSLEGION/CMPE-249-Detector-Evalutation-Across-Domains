# Primary report source

The primary submission PDF is ../main_experiment_report.pdf.
report.tex and figures/ are portable LaTeX sources generated from the same saved
experimental outputs. The PDF was produced with ReportLab and visually reviewed;
the LaTeX source was not compiled locally because no TeX distribution was available.

With a suitable LaTeX installation, build from this directory using pdflatex
report.tex. The code itself is supplied separately in the project src/ directory;
no Python listings are embedded in the report.
